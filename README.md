# PlotSPDS.NC

**PlotSPDS.NC** — программа автоматической печати чертежей nanoCAD с распознаванием форматов СПДС GraphiCS.

Программа распространяется в полнофункциональном виде. Использование доступно на основании коммерческой лицензии, срок действия которой подтверждается индивидуальным XML-файлом.

## Возможности

- автоматическое распознавание форматов СПДС GraphiCS;
- печать форматов из пространства модели и с листов;
- автоматический выбор ориентации формата: книжная или альбомная;
- автоматическое масштабирование форматов, в том числе при разных масштабах на одном чертеже;
- автоматический выбор устройства печати в зависимости от размера формата;
- печать форматов:
  - выбранных вручную на чертеже;
  - из активного чертежа;
  - из открытых чертежей;
  - из указанной директории;
- экспорт форматов из пространства модели на листы через видовые экраны.

## Загрузка

Готовые сборки публикуются на странице [GitHub Releases](https://github.com/doctorRaz/PlotSPDS.NC/releases).

Перед установкой ознакомься с описанием выбранного релиза: в нём указываются версия программы, состав архива и совместимость с версиями nanoCAD. Используй инструкции по установке, приложенные к конкретной сборке.

## Лицензирование

PlotSPDS.NC распространяется по коммерческой проприетарной лицензии. Публичная доступность дистрибутива не означает предоставления бесплатного права на использование программы.

Основные условия:

- право использования предоставляется после оплаты и выдачи действующей лицензии;
- лицензия действует в течение срока, указанного в XML-файле;
- лицензия привязывается к аппаратному идентификатору (HWID) компьютера;
- один выданный XML-файл предназначен для активации на соответствующем оборудовании и не может передаваться другому пользователю;
- при замене компьютера или существенном изменении оборудования можно обратиться к правообладателю за перевыпуском XML-файла; при перевыпуске сохраняется первоначальная дата окончания лицензии;
- оригинальный дистрибутив программы разрешено свободно распространять без изменений;
- распространение XML-файлов лицензий, модифицированных сборок и производных версий не разрешается.

Полные условия приведены в файле [LICENSE](LICENSE).
