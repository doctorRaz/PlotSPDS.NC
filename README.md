# PlotSPDS.NC

**PlotSPDS.NC** — программа автоматической печати чертежей nanoCAD с распознаванием форматов СПДС GraphiCS.

Программа распространяется в полнофункциональном виде. Для каждой новой версии релиза предоставляется бесплатный тестовый период продолжительностью 15 дней. В течение этого периода программа работает без коммерческой лицензии и без XML-файла активации. Для дальнейшего использования требуется коммерческая лицензия, срок действия которой подтверждается индивидуальным XML-файлом.

## Возможности

- автоматическое распознавание форматов СПДС GraphiCS;
- печать форматов из пространства модели и с листов;
- автоматический выбор ориентации формата: книжная или альбомная;
- автоматическое масштабирование форматов, в том числе при разных масштабах на одном чертеже;
- автоматический выбор устройства печати в зависимости от размера формата;
- печать форматов:
  - выбранных вручную на чертеже;
  - из активного чертежа;
  - из открытых чертежей;
  - из указанных директорий;
- экспорт форматов из пространства модели на листы через видовые экраны.

## Лицензирование

PlotSPDS.NC распространяется по коммерческой проприетарной лицензии. Публичная доступность дистрибутива не означает предоставления бесплатного права на бессрочное использование программы.

Основные условия:

- для каждой новой версии релиза предоставляется бесплатный тестовый период продолжительностью 15 дней, отсчитываемый с даты публикации релиза;
- в течение тестового периода программа доступна без коммерческой лицензии и без XML-файла активации;
- после окончания тестового периода для дальнейшего использования требуется действующая коммерческая лицензия;
- лицензия действует в течение срока, указанного в XML-файле лицензии;
- лицензия привязывается к аппаратному идентификатору (HWID) компьютера;
- один выданный XML-файл предназначен для активации на соответствующем оборудовании и не может передаваться другому пользователю;
- при замене компьютера или существенном изменении оборудования правообладатель может перевыпустить XML-файл лицензии по обращению пользователя;
- при перевыпуске сохраняется первоначальная дата окончания лицензии;
- оригинальный дистрибутив программы разрешено свободно распространять без изменений;
- распространение XML-файлов лицензий, модифицированных сборок и производных версий не разрешается.

Полные условия приведены в файле [LICENSE](LICENSE).
